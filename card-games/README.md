# card-games

브라우저에서 바로 돌아가는 카드 게임 모음과, 규칙 엔진을 화면에서 분리한 구현.
카드 그림은 전부 SVG로 직접 그려서 외부 이미지나 폰트 의존이 없습니다.

**[게임 열기](https://<계정>.github.io/card-games/)** · [화투 고스톱](https://<계정>.github.io/card-games/gostop.html)

> 위 주소는 Settings → Pages에서 소스를 `docs/` 폴더로 지정하면 생성됩니다.
> `<계정>` 부분을 본인 것으로 바꿔주세요.

## 게임

트럼프 8종이 하나의 선택 화면에 들어 있습니다. 난이도 순서이자 학습 순서입니다.

| | 게임 | 다루는 개념 |
|---|---|---|
| 01 | 워 | 셔플 · 비교 · 큐 |
| 02 | 하이로우 | 조건부 확률 |
| 03 | 메모리 | 2차원 배열 · 상태 관리 |
| 04 | 원카드 | 규칙 분기 · 특수 카드 |
| 05 | 블랙잭 | 조건 분기 · 소프트/하드 판정 |
| 06 | 홀덤 포커 | 조합 탐색 · 정수 인코딩 비교 |
| 07 | 카드운세 | 확률 · 희귀도 |
| 08 | 오늘의 운세 | 시드 고정 난수 · 재현성 |

화투 고스톱은 별도 페이지입니다. 파이썬 엔진과 JS 엔진 두 벌이 있습니다.

## 구조

```
web/        모듈 소스 — 여기를 고칩니다
docs/       빌드 결과물 — GitHub Pages가 서빙합니다
build.py    web/ → docs/ 조립
tests/      jsdom 브라우저 테스트 + 엔진 단위 검증
python/     고스톱 파이썬 엔진 (CLI 포함)
```

배포물이 단일 HTML인 이유는 셋입니다. Pages에 그대로 올라가고, 내려받아 더블클릭해도
열리며, 오프라인에서도 돕니다. 그래서 개발은 모듈로 하고 배포 직전에 합칩니다.

```bash
python3 build.py            # docs/ 재생성
python3 build.py --check    # 소스와 어긋나는지만 검사 (CI가 이걸 돌립니다)
```

`web/`을 고치고 빌드를 잊으면 CI가 막습니다.

## 설계 메모

**규칙과 화면을 분리했습니다.** 카드운세는 홀덤의 평가기를 그대로 씁니다 — 새 규칙을
한 줄도 쓰지 않고 화면만 붙였습니다. 게임을 추가하려면 `GAMES` 배열에 항목 하나와
`mount(root)` 함수 하나면 됩니다.

**족보를 정수 하나로 인코딩합니다.** `점수 = 카테고리 × 16⁵ + 킥커들` 형태라 두 핸드의
우열이 정수 비교 한 번에 끝납니다. "같은 투페어면 높은 페어가 이기고, 그것도 같으면
킥커로" 같은 중첩 분기가 전부 사라집니다.

**화투 카드에는 고유 id를 붙였습니다.** 10월 피처럼 속성이 완전히 같은 카드가 두 장씩
있어서, id 없이 동등 비교하면 `list.remove()`가 엉뚱한 장을 지웁니다. 자체 대국에서
48장이 안 맞는 것으로 발견했습니다.

## 검증

카드 게임은 통계로 검증하는 편이 단위 테스트보다 강력합니다. 규칙을 잘못 구현하면
확률이 눈에 띄게 어긋나기 때문입니다.

| 검사 | 방법 | 결과 |
|---|---|---|
| 포커 족보 판정 | 대표 패 15종 | 통과 |
| 포커 족보 분포 | 20만 회 시뮬레이션 | 9개 족보 전부 이론값과 일치 |
| 블랙잭 기본 전략 | 경계 사례 9종 | 통과 |
| 블랙잭 하우스 엣지 | 100만 판 | 0.44% (이론 0.4~0.6%) |
| 블랙잭 회계 | 100만 판 항등식 | 불일치 0건 |
| 고스톱 카드 보존 | 자체 대국 2천 판 | 항상 48장 |
| 화면 동작 | jsdom으로 8종 자동 조작 | 오류 0건 |
| 게임 전환 | 30회 진입/이탈 스트레스 | 오류 0건 |

하우스 엣지처럼 통계량인 항목은 시드 5개를 합산해 판정합니다. 단일 시드로는
±0.2%p씩 흔들려서 테스트가 불안정해집니다.

```bash
npm --prefix tests install
node tests/engines.test.js   # 규칙 엔진
node tests/smoke.js          # 브라우저 자동 조작
node tests/stress.js         # 게임 전환

pip install -e "./python[dev]"
pytest python -q             # 고스톱 파이썬 엔진
```

## 고스톱

파이썬 엔진은 CLI로도 돕니다.

```bash
pip install -e ./python
gostop --seed 42
```

시드를 주면 같은 판이 재현됩니다. 리플레이와 회귀 테스트에 그대로 씁니다.

규칙은 지역마다 다릅니다. 피박 기준, 따닥 정의, 국진 쌍피 처리 등 임의로 정한 부분은
`python/src/gostop/` 각 모듈의 주석에 적어뒀습니다.

## 알려진 한계

홀덤은 베팅 라운드를 하나로 줄였습니다. 실제로는 네 번이고 레이즈가 오갑니다.
딜러가 판단하지 않으므로 블러핑도 없습니다. 족보와 공유 카드 규칙은 실제 그대로입니다.

블랙잭 규칙은 6덱 · 딜러 소프트 17 스탠드 · 블랙잭 3:2 · 레이트 서렌더 조합입니다.
카지노마다 다르니 화면 하단 표기를 확인하세요.

카드 그림은 직접 그린 것이라 시중 카드보다 단순합니다. 시중 화투·트럼프의 인쇄
그림은 제작사 저작물이라 쓰지 않았습니다.
