# 나의 바이브코딩 도서관

수업에서 만든 작은 웹앱, 제작 프롬프트, 완성 웹주소와 GitHub 주소를 한곳에 기록하는 정적 웹앱입니다.

## 주요 기능

- 프로젝트 추가·수정·삭제
- 검색, 카테고리 필터, 즐겨찾기
- 제작 프롬프트 복사
- 완성 웹앱과 GitHub 저장소 연결
- 브라우저 자동 저장
- JSON 파일 내보내기·가져오기
- 모바일 반응형 화면

## 집에서 이어서 사용하는 방법

화면 위쪽의 **내보내기**를 눌러 JSON 백업 파일을 저장하세요. 다른 PC에서 사이트를 연 뒤 **가져오기**를 누르면 기록을 이어서 사용할 수 있습니다.

> 브라우저 자동 저장 자료는 기기마다 별도로 보관됩니다. PC를 바꿀 때는 JSON 내보내기·가져오기를 사용하세요.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다.

## GitHub Pages 발행

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
5. `main` 브랜치에 파일을 올리면 자동으로 발행됩니다.

GitHub의 **Actions** 메뉴에서 진행 상태와 완성된 주소를 확인할 수 있습니다.
